### a short paragraph about dataset and answers to questions

The dataset records NYC subway entrance and exit locations, including
the subway line and station name, coordinates, routes served, whether
entry is allowed, whether vending is available, entrance type, and ADA
compliance. I cleaned the column names first, selected the variables
that are required by the assignment, and converted entry from “YES”/“NO”
text to a logical variable. The resulting dataset has 19 total columns
and 1868 rows. The data are tidy.

### discussion, summary by inline R

This dataset has a descriptive row before the actual column names, so
`skip = 1` skips that row. I also used `na = "."` to treat missing MCI
onset ages as missing values. After cleaning the column names, `sex` and
`apoe4` are recorded as categories. Using `case_match` converts them
into non-numeric variables. There were 483 participants recruited in the
study, among them 97 developed MCI during follow-up. The mean baseline
age was 65.047 years. Of the 211 women, 63 were APOE4 carriers, so the
proportion was 0.2986.

``` r
amyloid <- read_csv("./hw2 data/data_mci/mci_amyloid.csv", skip = 1) %>%
  janitor::clean_names() %>% 
  pivot_longer(cols = baseline:time_8,
               names_to = "visit_time",
               values_to = "amyloid_ratio") %>% 
  mutate(visit_time_year = case_match(

    "baseline" ~ 0,
    "time_2" ~ 2,

    "time_8"~ 8
  )) %>% 
  relocate(visit_time_year, .before = amyloid_ratio) %>%
```

When importing this dataset, I also skipped the first row containing
descriptions by `skip = 1`. After cleaning the names, I used pivot to
transform the wide format into a long format, separating each
`visit_time` into different rows. And then I created a new column called
`visit_time_year` to store the time in numeric format (eg, baseline as
0, time_2 as 2). To have a clearer final view, I selected the three
columns to display: `study_id`, `visit_time_year`, `amyloid_ratio`.
